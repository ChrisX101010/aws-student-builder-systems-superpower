# AWS Amplify deployment

## Build

```bash
bash build_deploy_zip.sh
```

## Deploy

In AWS Amplify:

1. **Create new app**
2. **Deploy without Git**
3. App: `systems-superpower-hn`
4. Branch: `production`
5. Upload `systems-superpower-amplify.zip`
6. **Save and deploy**
